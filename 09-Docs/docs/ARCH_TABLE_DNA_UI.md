# Таблица выбора: Архитектура UI Мутаций (DNA Editor)
Тег: #igraspore_cloud

## Объекты сравнения:
1. **A (Canvas UI)**: Отрисовка всех кнопок и панелей напрямую в `ctx` игрового Canvas.
2. **B (CSS Glassmorphism)**: HTML/CSS Overlay поверх Canvas с использованием `backdrop-filter: blur()`, градиентов и CSS-транзиций.
3. **C (WebGL UI)**: Использование шейдеров для рендера UI-компонентов.
4. **D (Vanilla DOM)**: Обычные серые кнопки `button` и `div` без стилизации (текущий вариант).
