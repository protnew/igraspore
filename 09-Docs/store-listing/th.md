# Listing th

title: iGraSpore: จุลชีพ
short: บ่อน้ำตัดขวาง: กิน แบ่งตัว ซ่อนในสปอร์
critic: not scored

## Full

iGraSpore คือเกมจำลองเพื่อการเรียนรู้ ฟรี คุณคือเซลล์หนึ่งในบ่อน้ำ: กิน แบ่งตัว และสร้างสปอร์เมื่ออันตราย รอบตัวมีราวร้อยชนิด: พืชสีเขียว แบคทีเรีย ยูคาริโอตมีซิเลีย และผู้ย่อยสลาย (รา) มีไวรัสร่วมด้วย เลือกสิ่งมีชีวิตก่อนเริ่ม แถบล่างใช้ง่าย: กิน แบ่ง สปอร์ และอัตโนมัติ ส่วนอื่นอยู่ในเมนูพักเกม หากยังแบ่งตัวไม่ได้ ปุ่มจะบอกเหตุผล: พลังงาน มวล หรือพักสั้นๆ ไม่มีโฆษณา ไม่ต้องมีบัญชี ไม่เก็บข้อมูลผู้เล่น นี่คือโมเดลห่วงโซ่อาหาร ไม่ใช่ตำรา ชื่อสปีชีส์ละตินคงเดิม
