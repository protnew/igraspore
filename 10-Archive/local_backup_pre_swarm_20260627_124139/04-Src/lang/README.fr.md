| Créneau | Thrive | iGraSpore pourrait |

| Navigateur, sans installation | Non (télécharger Godot build) | Oui (un seul fichier HTML) |
| 100 espèces réelles | ~15 fictives | Taxonomies réelles |
| Simulation éducative | Jeu (divertissement) | Précision scientifique |
| Mobile dans le navigateur | Non | Oui |
| Intégration dans un site | Non | Oui |

Si on se démarque du clone et qu'on vise le créneau éducatif — le projet a du sens.
