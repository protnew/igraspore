# iGraSpore — 架构

## 概念
水坑中微生物生命的模拟。100种真实的细菌、原生动物、真菌物种。
带有阳光、营养物质、温度的无限2D地图。
玩家控制一个有机体，进化，吞噬其他有机体。

## 技术栈
- **单个HTML文件**（Canvas + JS）— 无需服务器，file:// 可用
- **无依赖** — 纯JS
- **GitHub Pages** — 部署

## 引擎架构
1. **World** — 无限地图（基于区块），每个区块 512×512 像素
2. **Environment** — 阳光（深度/时间）、温度、pH值、营养物质
3. **Organism** — 基类：位置、能量、大小、速度、DNA（参数）
4. **Species** — 100个预定义物种，具有真实特征
5. **Player** — 玩家有机体控制（WASD + 鼠标）
6. **Ecosystem** — 食物网：生产者 → 消费者 → 分解者
7. **Renderer** — Canvas 2D，摄像机跟随玩家，缩放

## 组织层次
- **生产者**（光合作用）：蓝藻、藻类
- **一级消费者**：捕食性细菌、小型鞭毛虫
- **二级消费者**：变形虫、纤毛虫
- **三级消费者**：大型原生动物、轮虫
- **分解者**：真菌、分解细菌

## 核心机制
- 细胞分裂（繁殖）
- 吞噬作用（进食）
- 光合作用（生产者）
- 化能合成
- 运动：鞭毛、纤毛、伪足
- 孢囊（不利条件下的休眠）
- 趋性：趋光性、趋化性
- 粘液和生物膜

## 操控
- WASD — 移动
- 鼠标 — 攻击/移动方向
- 空格 — 冲刺（消耗能量）
- E — 进食/吞噬
- Q — 分裂（能量充足时）
- Tab — 物种表
- 滚轮 — 缩放
