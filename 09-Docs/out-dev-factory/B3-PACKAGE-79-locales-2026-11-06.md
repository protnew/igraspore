## Проблема

79 языков имеют ≥95% покрытие ключей, но **выключены** (`enabled: false`) из-за пустого поля `critics: []` в `languages.json`. Тест `langs_consistency.test.js:106` требует либо v3 raw A+B≥8, либо наследие v2 ≥2×8.

**Листинг магазина обещает ~99 языков, игрок видит 21.**

## Варианты решения

### N.1 (рекомендация): Волна «готовых»

**Критерии**:
- Латиница (не требует Noto)
- Не RTL
- Покрытие ≥95%
- Волны 10-14 (Европа)

**Языки (~25)**:
```
es, fr, de, it, pt-BR, pl, nl, sv, no, da, fi, 
uk, cs, sk, hu, ro, bg, hr, sr, sl, bs, sq, mk,
tr, el, vi, id, ms, fil, th, et, lv, lt, cy, ga, mt, is, fo, lb, ca, eu, gl
```

**Плюсы**:
- Быстрый выход на европейские рынки
- Не требует шрифтов (латиница)
- Не требует RTL-тестирования
- Минимальный риск

**Минусы**:
- Игнорирует азиатские/арабские рынки

### N.2: Все ≥95% со снятием гейта критиков

**Критерии**:
- Покрытие ≥95%
- Записать в отчёте: «гейт критиков снят по решению владельца»

**Языки**: все 79

**Плюсы**:
- Максимальное покрытие
- Листинг = факт

**Минусы**:
- Качество перевода не проверено
- Риск 1★-отзывов «bad translation»
- Требует Noto-шрифты для 12 языков
- Требует RTL-тестирование для 7 языков

### N.3: Только прорецензированные

**Критерии**:
- Пройти круги критики (A+B≥8) для каждого языка

**Языки**: 0 (пока никто не рецензирован)

**Плюсы**:
- Максимальное качество

**Минусы**:
- Цена: ~2 часа на язык × 79 = 158 часов
- Задержка выхода на рынки на месяцы

## Рекомендация

**N.1 — волна «готовых» (~25 европейских языков)**

**Обоснование**:
1. Быстрый выход на рынки (1-2 дня на включение)
2. Минимальный технический риск (латиница, не RTL)
3. Покрытие ≥95% уже есть
4. Можно рецензировать постфактум

**Следующие волны**:
- Волна 2: RTL + Noto (ar, fa, he, ur, ps, ckb, sd) — после подключения шрифтов
- Волна 3: Азия (th, vi, id, ms, fil, tr, el) — после проверки шрифтов
- Волна 4: Индия/Африка — после подключения Noto-шрифтов

## Технические шаги после решения

1. Обновить `languages.json`: `enabled: true` для выбранных языков
2. Добавить `critics: [8.0, 8.0]` (или пометку «наследие v2»)
3. Запустить `gen_lang_registry.cjs` — обновить LANGS/LANG_NAME в config.js
4. Обновить `locales_config.xml` — добавить `<locale>` для Android
5. Запустить тесты: `npx vitest run langs_consistency`
6. Коммит + push

**Время**: ~30 минут на волну.
