# iGraSpore — Бэклог идей для перезапуска

## Условие перезапуска
Дистанцироваться от Thrive. НЕ делать «клон Spore». Делать уникальный продукт.

## Конкретные предложения

### 1. 🔬 BioLab Simulator — образовательная браузерная симуляция
**Ниша:** Встраиваемый образовательный модуль для школ/курсов биологии
- 100 реальных видов с научной точностью (не выдуманные)
- Параметры: реальный размер в мкм, реальная температура, реальный pH
- Учитель встраивает `<iframe>` на страницу курса
- Ученик наблюдает как экосистема лужи эволюционирует
- **Монетизация:** B2B продажа школам/университетам/курсам
- **Технически:** Один HTML файл, iframe-friendly, не нужен сервер
- **Thrive не конкурент:** Thrive = игра для гиков. Это = учебный инструмент

### 2. 📱 Microcosm — мобильная PWA «лужа в кармане»
**Ниша:** Casual симулятор на телефон (в браузере, без установки)
- Открываешь ссылку — видишь лужу с бактериями
- Touch управление: пальцем двигаешь организм
- Камера телефона = «микроскоп» (AR overlay?)
- Делиться лужой с друзьями (у каждой лужи свой seed)
- **Thrive не конкурент:** Thrive = desktop download 500MB+. Это = 1MB в браузере

### 3. 🧬 Taxonomy Explorer — интерактивная карта 100 видов
**Ниша:** Визуальная энциклопедия микроорганизмов
- Не игра, а интерактивный атлас
- Карта: кто кого ест, кто где живёт
- Фильтры: температура, pH, глубина, среда
- Каждый вид = карточка с реальными данными
- Можно «запустить симуляцию» для выбранного набора видов
- **Thrive не конкурент:** Thrive = игра. Это = справочник с симуляцией

### 4. 🎓 AI-преподаватель биологии на базе симуляции
**Ниша:** Связка с курсами Алексея «Нейросети против Иллюзий»
- Симуляция как наглядное пособие на лекции
- Студенты видят как AI управляет организмами
- Можно менять параметры и наблюдать последствия
- Формат: один HTML файл, работает с проектора
- **Связка с текущей работой Алексея:** Мегатоп AI-обучение + IBS преподавание

## Что сохранить при любом варианте
- БД 100 реальных видов (ТЗ уже готово)
- Параметрические таблицы (42 решения уже приняты)
- Стек: чистый JS + Canvas 2D, один HTML файл

## Когда вернуться
Когда появится 2-3 недели свободного времени и ясность по нише.
