## 1. Зачем одним экраном

**Проблема.** Игра уже играет, но кухня разъехалась: два набора кода, кнопка APK врёт, ключ подписи в git, два адреса сайта, таблицы выбора с фейковыми пруфами, бэклог говорит «всё готово».

**Решение.** По твоим решениям 22.09: сменить ключ и выложить честный APK на Cloudflare; оставить один актуальный код, старую видимую копию убрать в скрытый архив; добавить WebGL как ещё один стиль для сравнения; выключить GitHub Pages (репо не трогать); почистить бэклог; привести таблицы в Choser (скрытые, с тегом); починить доступность оболочки.

**Результат.** Один канон для игрока и агентов, честное приложение, можно глазами сравнить картинку WebGL и Canvas, внутренняя кухня выбора в порядке и не светится наружу.

## 3. Пакеты работ

### A. Новый ключ и честный APK на Cloudflare

**Проблема.** Ключ подписи лежит в git. По адресу APK сайт отдаёт HTML.

**Решение.**
1. Считать старый keystore скомпрометированным.
2. Создать новый keystore **вне** `C:\Obsidian\` и **вне git** (профиль ОС / менеджер паролей). Пароли не писать в md и чат.
3. Дождаться пакета **B** (канон кода), затем собрать/взять APK из канона (в т.ч. обновить `apk_proj/assets/www` из канона) и **подписать новым ключом**.
4. Выложить binary на `https://igraspore.pages.dev/igraspore.apk` как файл-asset (wrangler/dash), не через SPA fallback.
5. Кнопку APK сделать `<a>` или `<button>` с нормальным фокусом и подписью (часть a11y сразу здесь).
6. Старый keystore убрать из tracking + `*.keystore` в `.gitignore`.

**Результат.** Человек скачивает настоящее приложение; секрет не в репозитории.

**Проверка:** `git ls-files` без keystore; `curl -sI` на APK — не `text/html`, размер как у файла; клик в UI качает приложение.

### B. Один код + архив видимого дубля

**Проблема.** Сайт читает `04-Src`, тесты/правила — `.04-Src`, файлы разошлись. Видимый код тяжелит Obsidian.

**Решение.**
1. Сверка: md5 всех js в `04-Src/js` и `.04-Src/js`. Различия — в лог; по умолчанию в канон берём более новое/проверенное в `.04-Src`, конфликтные — с твоим взглядом если авто-выбор сомнителен.
2. Канон runtime = **`.04-Src`**. `index.html` (и деплой CF) грузит **это** дерево (или явная сборка-копия из канона в корень деплоя — один способ, зафиксировать в отчёте хода).
3. **До** удаления: полная копия текущего видимого `04-Src` → `C:\Obsidian\New\Projects\08-iGraSpore_V2\.10-Archive\04-Src-visible-snapshot-2026-09-22\` (только папка **с точкой** `.10-Archive`, не видимый `10-Archive`).
4. На месте `04-Src/` оставить тонкий README-указатель без `js/`.
5. Корневой `node_modules` убрать; зависимости под `.04-Src`.
6. Vitest/coverage привести к канону. Прототип `.04-Src/v3-webgl/` **не удалять** — он сырьё для пакета C.

**Результат.** Одна правда кода; архив не индексируется Obsidian.

**Проверка:** md5 runtime = то, что в index; нет тяжёлого `04-Src/js`; снимок в `.10-Archive`.

### C. WebGL как новый стиль

**Проблема.** Хочешь увидеть разницу WebGL и текущего Canvas, не ломая игру.

**Решение.**
1. Добавить `renderMode = webgl` рядом с cartoon/swiss (уже есть переключатель).
2. Опереться на `.04-Src/v3-webgl/` (shaders + render), встроить как стиль, не как второй сайт.
3. **Дефолт остаётся cartoon.** WebGL только по кнопке.
4. Если WebGL недоступен — сообщение и возврат в cartoon.
5. Обязательный отчёт «что совпадает / что отличается» от Canvas.
6. Shaders входят в деплой CF.

**Минимум для «можно сравнивать»:** видны мир и организмы, базовое движение/еда работают, переключение туда-обратно. Полный паритет всех эффектов — не обязателен в первом заходе.

**Результат.** В одном сайте переключил стиль и сравнил глазами.
