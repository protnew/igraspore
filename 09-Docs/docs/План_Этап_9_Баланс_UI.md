# План ребалансировки (Пищевая пирамида) и фиксов UI

Вы абсолютно правы: в текущей симуляции нарушены пропорции пищевой пирамиды (продуцентов должно быть подавляющее большинство), а также есть огрехи в верстке при небольших разрешениях экрана.

## ⚠️ Вопросы для вашего утверждения
> [!IMPORTANT]
> 1. Согласны ли вы на предложенные ниже стартовые лимиты для формирования крутой пирамиды?
> 2. Хотите ли вы, чтобы инфузории ели друг друга (каннибализм/хищничество внутри вида), или чтобы они ели только бактерий? (В плане я сделал их плотоядными).

## 1. Ребаланс экосистемы (`js/config.js`)
Экология работает по "правилу 10%". Чтобы прокормить хищников, нужно гигантское количество водорослей.
**Старые значения:** `TGT = {producer:220, consumer1:110, ...}`
**Новые значения:**
- Целевая популяция (`TGT`): `producer: 500, consumer1: 100, consumer2: 30, consumer3: 10, decomposer: 20`
- Стартовая популяция (`INIT_N`): `producer: 300, consumer1: 60, consumer2: 15, consumer3: 5, decomposer: 10`
- **Рацион:** Инфузории (`consumer2`) получают в свой массив `FOOD` дополнительную цель — `consumer2`, чтобы более крупные инфузории могли охотиться на мелких (хищничество внутри касты).

## 2. Исправление UI (Накладывание панелей)
В `index.html`:
- Класс `.scrollbox` (контейнер с карточками) получит гибкие свойства: `flex: 1; min-height: 0; max-height: 60vh;`, чтобы он динамически сжимался на небольших мониторах и не выталкивал кнопки.
- Меню `#menuO` получит `overflow-y: auto; padding: 20px 0;`, чтобы при нехватке места появлялся скролл всего окна, а не происходило сплющивание элементов друг на друга.
