# Таблица выбора: Архитектура Кинематографичной Камеры и Аквариума (Cinematic Aquarium) #iGraSpore_Cloud

**Контекст:** Необходимо реализовать режим "Аквариум" в главном меню (жизнь кипит на фоне) и умную кинематографичную камеру, которая замедляет время и фокусируется на интересных событиях (деление, поедание).

| Решение | Оценка | Обоснование | Пруфы / Детали |
| :--- | :---: | :--- | :--- |
| **1. Event-Driven Camera Tracker (Выбрано)** | **9/10** | Оптимально для симуляции. При вызове функций `eatOrg` или `finishDivide` генерируется событие. Камера захватывает координаты жертвы/хищника, включает `Lerp` (линейную интерполяцию) для плавного наезда и временно меняет множитель `timeScale`. | В играх типа Spore и RTS используется именно Event-Driven подход для фокусных камер (см. статьи GDC по камерам). Низкая нагрузка на CPU. |
| **2. Continuous Raycast / Scene Scoring** | **4/10** | Движок каждый кадр оценивает все объекты на экране и ищет "самое интересное место". | Слишком дорого O(N^2). При 1000 организмах сканирование сцены убьет 60 FPS. |
| **3. Hardcoded Waypoints** | **2/10** | Камера просто летает по заданным точкам или за случайными организмами. | Дешево, но скучно. Игрок не увидит экшена (съедения, деления). Не отвечает требованиям пользователя. |

# Таблица выбора: Архитектура Физики Жгутиков и Ресничек (Flagella/Cilia Physics) #iGraSpore_Cloud

**Контекст:** Требуется максимально реалистичное, "живое" отображение движения жгутиков и ресничек, чтобы бактерии выглядели как под настоящим микроскопом.

| Решение | Оценка | Обоснование | Пруфы / Детали |
| :--- | :---: | :--- | :--- |
| **1. Procedural Sine-Wave Kinematics (Выбрано)** | **9/10** | Математическая генерация (использование `Math.sin(time + offset)`) для отрисовки кривых Безье. Дает органичные, волнообразные движения без перегрузки памяти. Зависимость частоты волны от текущей скорости `speedMult` делает движение 100% реалистичным. | Стандарт для 2D-инди игр (Rain World использует схожую процедурную анимацию). Требует минимум памяти, вычисляется на лету в `render.js`. |
| **2. Sprite Sheet Animation** | **3/10** | Предзаписанные кадры (GIF/Sprite) для движения жгутиков. | Векторная игра. Спрайты убьют масштабируемость (зум) — при приближении микроскопа вылезут пиксели. Несовместимо с текущим стилем `Canvas 2D API`. |
| **3. Soft Body Physics (Verlet Integration) для хвостов** | **6/10** | Хвосты состоят из физических точек (nodes), которые тащатся за телом и пружинят. | Невероятно реалистично, но требует расчета столкновений и импульсов для каждого хвоста. Учитывая лимит в 1000+ бактерий, это критически снизит FPS браузера. Sine-Wave — лучшая иллюзия. |
