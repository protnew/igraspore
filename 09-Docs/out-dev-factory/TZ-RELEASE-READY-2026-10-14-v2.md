## 13. Ошибки и крайние случаи

- Словарь не загрузился (офлайн без кэша) → en из встроенного минимального словаря `config.js` (≤ 30 ключей меню) + тост.
- Шрифт не загрузился → системный fallback; canvas-текст перерисовать по `document.fonts.onloadingdone`.
- Язык выключен после установки (критик < 8 в обновлении) → сохранённый `igs_lang` указывает на выключенный → `detectLang` заново.
- Турецкий верхний регистр, немецкие длинные слова, тайский без пробелов — L.5, L.6, L.9.
- Числа: `Intl.NumberFormat(lang)`; hi — латинские цифры по умолчанию (`nu-latn`), чтобы HUD не прыгал по ширине.
