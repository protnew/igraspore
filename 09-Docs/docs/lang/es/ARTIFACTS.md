# iGraSpore — Artefactos del proyecto

## Qué es
Juego de simulación en navegador de 100 especies reales de microorganismos viviendo en un charco.
Canvas 2D, archivo HTML único, funciona sin servidor. Inspirado en Spore (etapa celular).
