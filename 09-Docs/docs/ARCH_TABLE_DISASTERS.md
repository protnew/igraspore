# Таблица выбора: Система Глобальных Катастроф (Global Disasters)
Тег: #igraspore_cloud

## Объекты сравнения:
1. **A (Global Override)**: Жесткое переопределение `lightLevel` и `pH` напрямую в Game Loop.
2. **B (Event Manager)**: Централизованный менеджер ивентов (`DisasterManager`), накладывающий модификаторы на глобальные переменные с таймерами.
3. **C (Chunk Modifiers)**: Локальное изменение свойств чанков (permanently или временно).
4. **D (Cell Debuffs)**: Навешивание статусов (`status: 'acid'`) на каждый организм индивидуально.
5. **E (Post-Processing)**: Только визуальный эффект через canvas `globalCompositeOperation`, без изменения физики.

**Обоснование:** Создание отдельного `EventManager` гарантирует гибкость (C1), чистый код (C4) и минимальное влияние на производительность (C3). Жесткие переопределения (A) ломают архитектуру, а дебаффы на каждой клетке (D) уничтожают O(1) производительность. Event Manager — идеальный архитектурный паттерн для случайных глобальных катаклизмов.
