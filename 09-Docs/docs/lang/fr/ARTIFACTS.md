# iGraSpore — Artefacts du projet

## Ce que c'est
Jeu de simulation navigateur de 100 espèces réelles de micro-organismes vivant dans une flaque.
Canvas 2D, fichier HTML unique, fonctionne sans serveur. Inspiré de Spore (stade cellulaire).
