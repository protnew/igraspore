# 🦠 iGraSpore — НА ПАУЗЕ

**Дата паузы:** 04.06.2026

## Почему пауза

Прямой конкурент: **[Thrive](https://revolutionarygamesstudio.com/)** — open-source эволюционная игра, 30+ разработчиков, годы работы, 3D, микробная стадия. Делает всё что планировали мы — но лучше.

**Но есть ниши, которые Thrive НЕ закрывает:**

| Ниша | Thrive | iGraSpore мог бы |
|---|---|---|
| Браузер, без установки | Нет (скачать Godot билд) | Да (один HTML) |
| 100 реальных видов | ~15 выдуманных | Реальные таксономии |
| Образовательная симуляция | Игра (развлечения) | Научная точность |
| Mobile в браузере | Нет | Да |
| Встраивание в сайт | Нет | Да |

Если дистанцироваться от клона и занять образовательную нишу — проект имеет смысл.
