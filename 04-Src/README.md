## Куда смотреть
- Реальный путь: **`.04-Src/`** (в корне проекта `08-iGraSpore_V2`)
- Полный путь Windows: рядом с этим README, папка с точкой в начале имени

## Зачем
Obsidian (Electron) падает/висит на «Кэш загружается…», если видит `node_modules`, архивы кода, coverage и т.п.  
Поэтому техника изолирована в скрытых папках (префикс `.`).

## Правила
1. **Не складывать код в эту видимую папку** — только этот README.
2. Весь новый код — в `.04-Src/` (или `.04-Src/...`).
3. Архивы — в `.10-Archive/` / `._АРХИВ/`, не в видимый `10-Archive/`.
4. Подробности: см. `AGENTS.md` / `CODE_ISOLATION.md` в корне проекта.
