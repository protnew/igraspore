# DAG — Зависимости задач

## Граф

```
T1 (настройка проекта) ──→ T2 (UI каркас) ──→ T3 (главный экран)
                      ├──→ T4 (API клиент)  ──→ T5 (интеграция)
                      └──→ T6 (CI/CD)      ──→ T7 (деплой)
```

## Список зависимостей

| Задача | Зависит от | Блокирует |
|---|---|---|
| T1 | — | T2, T4, T6 |
| T2 | T1 | T3 |
| T3 | T2 | — |
| T4 | T1 | T5 |
| T5 | T2, T4 | — |
| T6 | T1 | T7 |
| T7 | T6 | — |

## Критический путь
T1 → T2 → T3 (или T1 → T4 → T5) — самая длинная цепочка.
