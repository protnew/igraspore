# LANGUAGES: 20 языков игры без RTL + 32 языка листинга — 2026-10-14

project_tag: 08-iGraSpore · основание: решение Алексея 14.10 (без RTL; 20 языков в игре; стор 30+), `CHOICE-LANGUAGES-2026-10-14.md`, `COMPETITORS-PLAY-2026-10-14.md`

**Проблема:** в переключателе 11 языков, реально переведены 2 (ru, en); арабский в списке — RTL, который владелец исключил; цель — 20 языков полного контента (UI, туториал, тосты, вики 100 видов, листинг стора).
**Решение:** 20 языков без RTL двумя волнами (10 к релизу, 10 через 2–3 недели после релиза), листинг Google Play — 32 языка; шрифты по письменностям; ревью каждого языка ИИ-критиками по глоссарию видов.
**Результат:** игра на родном языке для стран, дающих по AppTweak 2025 не менее ~60 % загрузок Play (оценка); 0 языков-«пустышек» в переключателе.

## Таблица 3. Шрифты (что нужно)

| Письменность | Языки | Решение | Размер (оценка) | Риск |
|---|---|---|---|---|
| Latin / Latin Ext / Vietnamese | en, pt-BR, es, id, tr, de, fr, vi, fil, it, pl, ms | текущий шрифт игры + проверка покрытия Latin Ext-A и Vietnamese; иначе Noto Sans (subset latin, latin-ext, vietnamese) | ~30–60 КБ woff2 на subset | «тофу» □ на ệ/ł |
| Cyrillic | ru, uk | уже есть (ru работает) | 0 | ї/ґ проверить |
| CJK | ja, ko, zh-TW | Android: системный Noto CJK (без вшивания), веб: `font-family: system-ui, "Noto Sans JP/KR/TC"`; вшивать только subset строк игры (glyphhanger/pyftsubset) | 0 (системный) / 200–800 КБ subset | вес сборки, canvas-текст |
| Devanagari | hi | Noto Sans Devanagari (shaping делает браузер) | ~100–200 КБ | конъюнкты на canvas |
| Bengali | bn | Noto Sans Bengali | ~100–200 КБ | то же |
| Thai | th | Noto Sans Thai + перенос по словам `Intl.Segmenter('th',{granularity:'word'})` | ~40–80 КБ | обрезка, нет пробелов |

Если текст рисуется на `<canvas>`/WebGL (подписи видов, HUD-цифры) — шрифт обязан быть загружен (`document.fonts.load`) до первой отрисовки, иначе первый кадр с □. Это тест L.9 в ТЗ v2.
