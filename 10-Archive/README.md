# 10-Archive

Часть архивов проекта.

## Изоляция Obsidian
Если в корне есть **`.10-Archive/`** (с точкой) — туда уехал тяжёлый дамп (js/ts/node_modules-копии), чтобы Obsidian не индексировал десятки тысяч файлов.

- Тяжёлое → `.10-Archive/`
- Лёгкие md/бэкапы заметок могут оставаться здесь
- Новый тяжёлый мусор **не класть** в видимый `10-Archive/` без точки

См. также: `CODE_ISOLATION.md`, `AGENTS.md`
