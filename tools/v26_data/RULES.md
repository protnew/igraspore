# Правила переводчика v26 (для всех субагентов-переводчиков)

Проект: iGraSpore V2 — 2D-симулятор микробов (веб + Android). Переводим интерфейс и вики: живой пруд, виды микробов, меню, подсказки.

## Общие правила (нарушение = брак)

1. **Переводи на целевой язык реально.** Копировать английское значение ЗАПРЕЩЕНО (кроме случая, когда слово в целевом языке действительно пишется так же — международные термины: DNA→ДНК-аналоги, pH, PCR и т.п.). Не бери слова из других языков проекта.
2. **Плейсхолдеры сохраняй точно:** {n}, {kinds} и любые {xxx} — без изменений, на исходном месте по смыслу.
3. **Длина:** не длиннее английского оригинала больше чем в 1.6 раза; для HUD-кнопок (hud.btn.*.short) — до 8 символов, hud.btn.* — до 14.
4. **Научные названия видов** (латынь: Synechocystis, E. coli, Streptomyces coelicolor) — оставляй латиницей как есть; описательную часть переводи.
5. **Стиль:** коротко, по-человечески, без канцелярита; как в хороших мобильных играх. «Pond» = пруд/водоём в контексте игры (небольшой водоём). Названия категорий (producer/consumer/decomposer/predator) переводи устоявшимися словами языка.
6. **Регистр:** у кнопок в en CAPS-стиль (например "PLAY") — в целевом языке используй принятую в языке форму (для языков с капсом — капс, для остальных — обычная форма с заглавной).
7. **Формат файла:** ВАЛИДНЫЙ JSON-объект без комментариев, кодировка UTF-8, одна строка-значение (без \n внутри, кроме helpTouch/help* — там HTML <p> можно).
8. **Файл писать целиком одним вызовом записи, затем ПРОВЕРИТЬ парсинг** (node -e "JSON.parse(require('fs').readFileSync(...))") и отчёт: сколько ключей.

## Словарь (dict): C:\Obsidian\New\Projects\08-iGraSpore_V2\tools\v26_data\<lang>.dict.json

- Источник: C:\Obsidian\New\Projects\08-iGraSpore_V2\.04-Src\i18n\en.json (436 ключей) — перевести ВСЕ ключи.
- Формат: { "ключ": "перевод", ... } — ровно те же ключи, что в en.json.
- Особые группы ключей:
  - sp.* — названия видов в игре: переводи описательную часть (например "T4 Bacteriophage" → «Бактериофаг T4»), латинские биномены не переводить.
  - loc.* — короткие слова о движении (≤18 символов).
  - dTip.* — подсказки о причинах смерти, полные предложения.
  - wiki.* — интерфейс вики (заголовки, поиск).
  - helpTouch / help* — короткий HTML-текст управления (теги <b>, <p> сохранять).
  - Ключи с {n}/{kinds} — подставь плейсхолдеры как в en.
  - speciesShown/coloniesCount/aliveCount — формы множественного числа: делай formу для «other» (родительный множественный), если в языке нет категории other — используй наиболее общую форму.
