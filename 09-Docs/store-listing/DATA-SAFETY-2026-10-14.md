# Data safety — черновик для консоли, 14.10.2026

В эту форму не ставить сбор данных. Решение про аналитику не принято, поэтому аналитики в сборке нет. Аккаунта нет. Рекламы нет. Публикацию это не разрешает.

| Вопрос консоли | Ответ для этой сборки |
|---|---|
| Собирает ли приложение данные | Нет |
| Передаёт ли данные | Нет |
| Имя, почта, геолокация, контакты, фото, рекламный id, финансы | Не собираются |
| Выбор языка и настройки | Только на устройстве, в localStorage. На сервер не уходят |
| Шифрование при передаче | Не применимо: передачи нет |
| Удаление по запросу | Не применимо: аккаунта нет |
| Реклама | Нет |
| IARC | Заполняет Алексей в консоли. В политике нет насилия, покупок и рекламы |

Если позже будет отдельное «да» на аналитику, эту страницу надо переписать до публикации.
