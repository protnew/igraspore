## ⚠️ Открытые вопросы для утверждения

> 2. Подтверждаете ли вы предложенное техническое распределение кода по модулям (см. ниже)?

## Техническое распределение задач по модулям

### 1. `js/config.js` (Конфигурация и База Данных)
- Добавить глобальные флаги: `window.spectatorMode = false;`, `window.audioCtx = null;`.
- Пройтись скриптом по массиву `SPECIES` и добавить каждому виду свойство `optT` (от 15 до 30 градусов), чтобы не править каждую из 100 строк вручную.

### 2. `js/world.js` (Игровая логика)
- В функции `updateOrganism(org, dt)` (или эквивалентной ИИ/игрока функции) добавить расчет штрафа за температуру: `Math.abs(ch.temp - sp.optT)`.
- В местах, где происходит `org.energy *= 0.5` (деление) или обнуление цели (поедание), добавить вызов новой функции `playSound('divide')` и `playSound('eat')`.
- В блоке управления камерой (`updateCamera`) добавить условие: если `spectatorMode` активен, камера вычисляет самого крупного `alive` организма и плавно центрируется на нем.

### 3. `js/main.js` (Игровой цикл и Инициализация)
- Внедрить `AudioContext` и функцию-синтезатор `playSound(type)`. Использование Web Audio API гарантирует отсутствие внешних зависимостей.
- Создать функцию `startSpectator()`, которая устанавливает `spectatorMode = true`, включает аудио и запускает игру без создания объекта Игрока.

### 4. `js/ui.js` (Пользовательский интерфейс)
- Отредактировать отрисовку HTML для Главного Меню, добавив кнопку "Режим Наблюдателя".
- Модифицировать функцию рендера Каталога Видов (Taxonomy Explorer), чтобы вместо колонки 'Форма' выводилась 'Идеальная t (°C)', а у размера появилась приписка 'мкм'.
- Обновить левый HUD, чтобы он показывал текущую температуру в чанке игрока.

## План развертывания
1. Применение патчей к 4 JS-модулям через файловую систему.
2. Прогон синтаксической проверки `node --check`.
3. `git add .`, `git commit -m "feat: AI-Tutor, Temp mechanics, Web Audio"`.
4. `git push origin main`.
5. Выдача вам ссылки **https://protnew.github.io/igraspore/**.
