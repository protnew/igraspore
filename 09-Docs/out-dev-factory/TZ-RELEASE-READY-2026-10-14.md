## 0. Коротко для Алексея: Проблема → Решение → Результат

- **Проблема.** На экране игры 30 кнопок и 8 панелей (на телефоне 27 + джойстик). Из 48 проверенных элементов 4 сломаны полностью, 5 — частично. ## 5. Этапы

### P0. Сломанные кнопки (приоритет 1)

#### P0.1 🔴 ЦИСТА/СПОРА (R) не включается
- Проблема: `doCyst` ставит `cyst=true`, а `biology_update_interact.js:66-69` будит игрока в том же кадре при `energy>=18`, тост «Проснулся из цисты». Прогон: 0 кадров в цисте из 16–20 (`audit2-result.json`, ключи `R`, `bCyst`); `1280-08-cyst.png`.
- Решение: в `doCyst` (`biology_eat.js:239`) для игрока — флаг `o.manualCyst=true`, `o.cystMin=5` с; авто-пробуждение (`:66`) только если `!o.manualCyst || o.cystT>=o.cystMin` **и** игрок впал в цисту от голода; выход — повторное R/кнопка. Тосты: вход «Спора: защита, движение 0, энергия тратится медленно», выход «Вышел из споры». Кнопка `#bCyst` получает класс `is-on`.
- Приёмка: R → `player.cyst===true` ≥ 5 с подряд (≥ 250 кадров при 60 fps / по времени); повторное R после 5 с → false; хищник не ест цисту (ai.js:131 уже фильтрует).
- Тест: vitest `cyst_manual.test.js` (поведение `updateOrgInteract`); Playwright `hud_contract.spec.js` шаг «R».
- Откат: копия `biology_eat.js`, `biology_update_interact.js` в `.10-Archive\release-ready-2026-10-14-before\`.

#### P0.2 🔴 ДЕЛИТЬ (Q) почти всегда «перезарядка»
- Проблема: игрок делится сам (`biology_update_interact.js:48-51`, `divP = o.isPlayer ? 0.5 : 0.02`) → `divCD` 20–34 с, Q отвечает «перезарядка». Пороги массы различаются: `canDivide` `biology.js:57-66` ≠ `divideBlockReason` `biology.js:80-85` ≠ `updateDivReady` `ui.js`. `settings.divRate<1` — случайный тихий отказ `biology.js:93-94`.
- Решение: (а) авто-деление игрока только при `autoAI===true` (решение 🔴 №1); (б) одна функция `divideNeeds(o)` → `{ok, energy:[cur,need], mass:[cur,need], size:[cur,need], age, cd, reason}`, её используют `canDivide`, `divideBlockReason`, `updateDivReady`; (в) `divRate` не влияет на игрока; (г) кнопка `#bDiv`: класс `is-ready` (зелёная) / `is-blocked` (серая) + кольцо прогресса `--p` 0–100 % и подпись-причина под кнопкой («энергия 40/63», «перезарядка 12 с»).
- Приёмка: в состоянии `is-ready` нажатие Q даёт `dividing=true` за ≤ 1 кадр и +1 клетка вида через ≤ 1,5 с в 20 из 20 попыток; без нажатия и без АВТО игрок за 60 с не делится (0 делений); подпись причины совпадает с `canDivide` в 100 % из 200 случайных состояний (vitest).
- Тест: `divide_contract.test.js`, `hud_contract.spec.js` шаг «Q».
- Откат: как P0.1 (`biology.js`, `biology_update_interact.js`, `ui.js`, `main_events.js`).

#### P0.3 🔴 ЕСТЬ (E) у растения молча ничего не делает
- Проблема: `main_events.js:153` `if(player.sp.cat==='producer') return false;` без тоста; вид по умолчанию — Synechocystis (producer). Подпись клавиши «авто» вместо E (`main.js:371`).
- Решение: слить `#bEat` и `#bFeed` в одну кнопку «ЕСТЬ» (E и Space → один обработчик); для producer — кнопка «☀ СВЕТ» с тостом «Ты растение: плыви к свету» и стрелкой вверх; вид по умолчанию в меню — охотник consumer1 (решение 🟡 №8).
- Приёмка: у каждого из 4 типов (producer, consumer1, consumer2, decomposer) нажатие даёт тост или изменение энергии/массы ≠ 0 за 1 с — 4/4.
- Тест: `hud_contract.spec.js` шаг «E» × 4 вида.
