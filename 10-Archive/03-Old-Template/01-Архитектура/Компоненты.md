# Компоненты — [НАЗВАНИЕ ПРОЕКТА]

## Модули

| Модуль | Зона ответственности | Файлы | Статус |
|---|---|---|---|
| Frontend | UI, рендеринг, ввод | `05-src/frontend/` | 🟡 в работе |
| Backend | API, бизнес-логика | `05-src/backend/` | 🔴 не начат |
| DB | Хранение данных | — | 🟢 готово |

## Зависимости между модулями

```
Frontend → API → Backend → DB
```

## Границы ответственности
- **Frontend:** только отображение и ввод. Никакой бизнес-логики.
- **Backend:** только API и валидация. Никакого UI.
- **DB:** только хранение. Никаких вычислений.
