# iGraSpore — Ideas Backlog for Restart

## Restart condition
Distance from Thrive. Do NOT make a "Spore clone". Build a unique product.

## Specific proposals

### 1. 🔬 BioLab Simulator — Educational Browser Simulation
**Niche:** Embeddable educational module for schools/biology courses
- 100 real species with scientific accuracy (not fictional)
- Parameters: real size in μm, real temperature, real pH
- Teacher embeds `<iframe>` on course page
- Student observes how puddle ecosystem evolves
- **Monetization:** B2B sales to schools/universities/courses
- **Technically:** Single HTML file, iframe-friendly, no server needed
- **Thrive is not a competitor:** Thrive = game for geeks. This = educational tool

### 2. 📱 Microcosm — Mobile PWA "puddle in your pocket"
**Niche:** Casual simulator on phone (in browser, no install)
- Open link → see a puddle with bacteria
- Touch control: finger moves organism
- Phone camera = "microscope" (AR overlay?)
- Share puddle with friends (each puddle has unique seed)
- **Thrive is not a competitor:** Thrive = desktop download 500MB+. This = 1MB in browser

### 3. 🧬 Taxonomy Explorer — Interactive map of 100 species
**Niche:** Visual microorganism encyclopedia
- Not a game, but an interactive atlas
- Map: who eats whom, who lives where
- Filters: temperature, pH, depth, environment
- Each species = card with real data
- Can "run simulation" for selected set of species
- **Thrive is not a competitor:** Thrive = game. This = reference with simulation

### 4. 🎓 AI Biology Teacher based on simulation
**Niche:** Linked to Alexey's courses "Neural Networks vs Illusions"
- Simulation as visual aid in lectures
- Students see how AI controls organisms
- Can change parameters and observe consequences
- Format: single HTML file, works from projector
- **Links to Alexey's current work:** Megatop AI training + IBS teaching
