### Что меняется радикально
1. Canvas → **WebGL raw** — шейдеры для воды/света/постобработки
2. GitHub Pages → **Vercel** — мгновенный деплой без кэша
3. drawImage → **Instanced rendering** — 2000 объектов без лага
4. Случайный старт → **Катсцена** — камера сверху, плавный зум

### Что остаётся
FSM AI, Grid коллизии, HTML overlay UI, JSON inline, чистый HTML

### Этапы миграции (8 дней)
1. Phase 1 (2д): WebGL context + ortho camera + boilerplate
2. Phase 2 (2д): Water shader (Perlin noise + caustics)
3. Phase 3 (1д): Instanced rendering для 2000 организмов
4. Phase 4 (1д): FBO постобработка (bloom, god rays)
5. Phase 5 (1д): Lily pads как displaced planes
6. Phase 6 (0.5д): Катсцена старта
7. Phase 7 (0.5д): Vercel deploy
