# Политика конфиденциальности
<p class="updated](Последнее обновление: 12 августа 2026 г.

<div class="section](
## 1. Общие положения
Игра «iGraSpore — симулятор микромира» (далее «Приложение») — это образовательная игра-симулятор экосистемы микроорганизмов. Приложение не требует регистрации, не запрашивает личные данные и не собирает персональную информацию пользователей.
</div>

<div class="section](
## 2. Данные, которые НЕ собираются
Приложение НЕ собирает, НЕ хранит и НЕ передаёт:

- Имя, адрес электронной почты, номер телефона</li>
- Точное местоположение (GPS)</li>
- Контакты, сообщения, фотографии</li>
- Идентификаторы устройств (IMEI, Advertising ID)</li>
- Финансовую информацию</li>

</div>

<div class="section](
## 3. Локальные данные
Приложение сохраняет настройки игры (выбранный вид организма, режим отображения) в локальном хранилище устройства (localStorage / SharedPreferences). Эти данные:

- Хранятся только на устройстве пользователя</li>
- Не передаются на серверы</li>
- Удаляются при удалении приложения или очистке данных браузера</li>

</div>

<div class="section](
## 4. Возраст пользователей
Приложение предназначено для всех возрастов. Контент не содержит насилия, неприемлемого контента или встроенных покупок.
</div>

<div class="section](
## 5. Реклама
Приложение не содержит рекламы и не использует рекламные SDK.
</div>

<div class="section](
## 6. Сторонние сервисы
Приложение не использует сторонние аналитические сервисы, SDK отслеживания или социальные плагины.
</div>
