# iGraSpore — Аритектура

## Концепция
Симуляция жизни микроорганизмов в луже. 100 реальных видов бактерий, простейших, грибков.
Бесконечная 2D карта с солнечным светом, питательными веществами, температурой.
Игрок управляет одним организмом, эволюционирует, поедает других.

## Стек
- **Один HTML файл** (Canvas + JS) — работает без сервера, file:// OK
- **Никаких зависимостей** — чистый JS
- **GitHub Pages** — деплой

## Архитектура движка
1. **World** — бесконечная карта (chunk-based), каждый чанк 512×512 px
2. **Environment** — солнечный свет (глубина/время суток), температура, pH, питательные вещества
3. **Organism** — базовый класс: позиция, энергия, размер, скорость, ДНК (параметры)
4. **Species** — 100 предустановленных видов с реальными характеристиками
5. **Player** — управление организмом игрока (WASD + мышь)
6. **Ecosystem** — food web: продуценты → консументы → редуценты
7. **Renderer** — Canvas 2D, камера следует за игроком, зум

## Уровни организации
- **Продуценты** (фотосинтетики): цианобактерии, водоросли
- **Консументы I порядка**: бактерии-хищники, мелкие жгутиконосцы
- **Консументы II порядка**: амёбы, инфузории
- **Консументы III порядка**: крупные простейшие, коловратки
- **Редуценты**: грибы, бактерии-деструкторы

## Ключевые механики
- Деление клеток (размножение)
- Фагоцитоз (поедание)
- Фотосинтез (продуценты)
- Хемосинтез
- Движение: жгутики, реснички, псевдоподии
- Цисты (покой при неблагоприятных условиях)
- Таксис: фототаксис, хемотаксис
- Слизь и биоплёнки

## Управление
- WASD — движение
- Мышь — направление атаки/движения
- Пробел — ускорение (тратит энергию)
- E — поедание/фагоцитоз
- Q — деление (когда энергия достаточна)
- Tab — таблица видов
- Scroll — зум
