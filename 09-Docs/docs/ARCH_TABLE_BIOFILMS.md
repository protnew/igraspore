# Таблица выбора: Механика сцепления Биопленок (Biofilms Physics)
Тег: #igraspore_cloud

## Объекты сравнения:
1. **A (Spring)**: Пружинные силы (Hooke's Law) между соседними клетками (притяжение/отталкивание).
2. **B (Boids)**: Мягкое следование (Velocity matching & Cohesion) без жестких связей.
3. **C (Verlet)**: Жесткие констрейнты (Rigid Body Joints / Verlet integration).
4. **D (Hex)**: Привязка к гексагональной сетке относительно "корневой" клетки (Grid Snapping).
5. **E (Aggregate)**: Слияние нескольких объектов в один Entity с множеством хитбоксов.

## Winner: A (Spring Force)
**Запас (Margin):** 6 баллов по сравнению с Boids.

**Обоснование:** Spring Force обеспечивает идеальный баланс между реалистичной физикой вязкой слизи биопленок и высокой производительностью (через spatial hash). Boids был близок, но он имитирует стаю рыб, а не физически связанную колонию микроорганизмов, что разрушает реалистичность (C1). Обязательно применение `clamp` для защиты от физических взрывов при высоком `dt` (слабое место C9).
