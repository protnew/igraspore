# Google Play Store Listing — iGraSpore

## Название приложения
iGraSpore — симулятор микромира

## Краткое описание (80 символов)
Симулятор экосистемы: 100+ реальных видов микроорганизмов в одной капле воды.

## Полное описание (4000 символов)
iGraSpore — это образовательная игра-симулятор, которая воспроизводит жизнь микромира в капле воды. Управляйте реальными видами микроорганизмов — от цианобактерий до инфузорий — в интерактивной экосистеме, где каждый вид играет свою роль.

ОСНОВНЫЕ ВОЗМОЖНОСТИ:

‣ 100+ реальных видов микроорганизмов с научной точностью
‣ 3 режима отображения: мультяшный, биоиконки, SwissBioPics-диаграммы
‣ Играй за любое звено пищевой цепи: производитель, потребитель, хищник, вирус
‣ Реалистичная симуляция: метаболизм, деление клеток, хемотаксис
‣ Динамическая среда: смена дня и ночи, сезоны, температурные градиенты
‣ Особый режим «Вирус» — управляйте бактериофагом и заражайте бактерии
‣ 7 звёздных систем с разным спектром освещения
‣ Полностью офлайн — играй без интернета

НАУЧНАЯ ОСНОВА:
Виды и их характеристики основаны на базе данных NCBI Taxonomy и SwissBioPics. Визуализация клеток соответствует канонам биологических иллюстраций.

УПРАВЛЕНИЕ:
Мультитач: перемещение, масштабирование, действия. Клавиатура: WASD для перемещения, +/- для масштаба.

Доступно для всех возрастов. Без рекламы, без встроенных покупок.
