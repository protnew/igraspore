# a11y оболочки — 2026-09-22

**Проблема.** Мало подписей и нормального фокуса.

**Решение.** Кнопка APK = `<a>` с `aria-label`; `:focus-visible` outline 2px; aria-label на ключевых id (renderMode, pause, wiki, settings, start…).

**Результат.** Оболочкой можно пройти Tab на основные контролы. Полный axe-прогон в браузере — желателен как следующий шаг.

Контраст кнопки APK: фон `#0a4a52`, текст `#5ed4a0` (целевой ≥4.5:1 — визуально ок для UI акцента; при замечаниях подкрутить).
