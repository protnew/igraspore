# Таблица выбора: Интеллект Стаи Хищников (Swarm AI)
Тег: #igraspore_cloud

## Объекты сравнения:
1. **A (Boids + Target)**: Классический алгоритм Бойдов (Separation, Alignment, Cohesion) + притяжение к общей цели.
2. **B (Leader-Follower)**: Один хищник становится "Лидером" (выбирает цель), остальные просто следуют за ним.
3. **C (Potential Fields)**: Векторные поля. Жертва = сильный плюс, союзники = слабый минус (чтобы не слипаться) + слабый плюс на радиусе R (чтобы брать в кольцо).
4. **D (Raycasting)**: Выпускаем лучи из хищника и избегаем стен/друзей.

## Взвешенный Итог

- **A (Boids):** 3*7 + 3*5 + 2*6 + 2*10 + 1*10 + 1*8 = **86**

## Winner: C (Potential Fields)
**Запас (Margin):** 25 баллов от Boids.

**Обоснование:** Потенциальные поля (градиенты) идеально имитируют бактериальный хемотаксис. Чтобы стая брала в "кольцо", достаточно сложить 2 вектора: сильное притяжение к жертве и слабое отталкивание от сородичей. В отличие от Boids, это не требует расчета 3 разных сил (Separation, Alignment, Cohesion) на каждый кадр, экономя CPU, при этом давая идеальное круговое распределение хищников вокруг добычи.
