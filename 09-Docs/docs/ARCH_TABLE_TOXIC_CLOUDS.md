# Таблица выбора: Механика Токсичных Облаков (Toxic Clouds)
Тег: #igraspore_cloud

## Объекты сравнения:
1. **A (Particle-based)**: Облако состоит из 100+ физических частиц, которые разлетаются и исчезают.
2. **B (Grid-based)**: Глобальная 2D-сетка (Cellular Automata), где яд диффундирует между ячейками (как fluid simulation).
3. **C (Entity-based AoE)**: Один скрытый объект `ToxinCloud` с радиальным градиентом, который увеличивается в радиусе и теряет концентрацию (alpha).
4. **D (Post-Process Shaders)**: Использование шейдеров WebGL для расчета облаков.

## Критерии и оценки

| --- | --- | --- | --- | --- |

Пруф: [Matrix updates] | 9/10: Всего 50 проверок `dist2()`. Пруф: [Circle collision] | 8/10: GPU вычисления, но дорого для Canvas2D гибрида. Пруф: [WebGL overhead] |
| **C3. Динамика рассеивания (2)** | 8/10: Физически корректно. Пруф: [Brownian motion] | 10/10: Идеальная диффузия. Пруф: [Navier-Stokes] | 7/10: Простое увеличение радиуса и снижение alpha. Пруф: [Lerp] | 9/10: Шейдерный шум. Пруф: [Perlin noise] |

- **D (Shaders):** 3*10 + 3*8 + 2*9 + 2*1 + 1*2 + 1*7 + 1*5 = **88**

## Winner: C (Entity-based AoE)
**Запас (Margin):** 5 баллов от Grid CA.

**Обоснование:** Несмотря на то, что Grid CA (B) дает идеальную физику жидкостей, его CPU-оверхед слишком высок для браузерной игры, в которой уже 3000 объектов. Подход Entity-based (C) — это создание невидимых кругов, которые ИИ легко обходит, а рендер просто рисует радиальные градиенты. Это дает 80% визуального эффекта за 5% цены производительности, что критично для нашего проекта.
