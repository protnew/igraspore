# 🦠 iGraSpore — 暂停

**状态：** ⏸️ 暂停，直到找到独特的定位（不是 Thrive 的克隆）
**暂停日期：** 2026年6月4日

## 为什么暂停

直接竞争对手：**[Thrive](https://revolutionarygamesstudio.com/)** — 开源进化游戏，30+ 开发者，数年开发，3D，微生物阶段。它实现了我们计划的一切 — 但更好。

**但 Thrive 没有覆盖的领域：**

| 领域 | Thrive | iGraSpore 可以 |
|---|---|---|
| 浏览器，无需安装 | 否（需下载 Godot 构建） | 是（单个 HTML 文件） |
| 100个真实物种 | 约15个虚构物种 | 真实分类学 |
| 教育模拟 | 游戏（娱乐） | 科学准确性 |
| 手机浏览器 | 否 | 是 |
| 嵌入网站 | 否 | 是 |

如果我们摆脱克隆定位，瞄准教育领域 — 这个项目是有意义的。
