# Таблица выбора: Мега-спринт из 30 улучшений (Часть 1)
Теги: #igraspore_cloud #sprint30 #features

| Решение | Оценка (0-10) | Обоснование | Пруфы / Детали реализации |
| --- | --- | --- | --- |
| **Камера: Орбитальный фокус** | 10/10 | Решает проблему "побега" камеры за границы экрана. Привязка к абсолютному центру с синусоидальным смещением удерживает аквариум в фокусе всегда. | `world.js` -> `cam.x = Math.sin(gt) * (PW*0.4); cam.y = PD/2 ...` |
| **Стенки водоема: Отрисовка породы (Земля)** | 10/10 | Убирает эффект "прозрачных границ". Вода теперь находится в физическом "бассейне" / пруду, что радикально повышает визуальную глубину. | `render.js` -> `renderWater()`. Отрисовка `-PW-500` и `+PW+500` с цветом `#0f0c08`. |
| **3D Звук (Пространственный звук)** | 9/10 | Позволяет на слух определять, где (слева или справа) происходит поедание или деление клеток. Важный элемент погружения. | `main.js` -> `playSound(type, x, y)` через `createStereoPanner()`. |
| **Биолюминесценция планктона** | 9/10 | Ночью экран становится слишком темным. Если планктон светится, ночные сцены выглядят потрясающе. | `render.js` -> `ctx.shadowBlur` для `cat === 'producer'` при `dayLight < 0.3`. |
| **Dash (Рывок хищника)** | 8/10 | Динамика погони. Хищники (consumer2,3) делают резкий рывок при приближении к добыче. Делает ИИ опаснее. | `world.js` -> `updateOrg()`. Увеличение `o.vx` на 10 при сближении с целью. |
| **Сохранение Рекордов (LocalStorage)** | 10/10 | Игрок должен видеть свой прогресс между сессиями (Макс размер, время жизни). Иначе теряется смысл выживания. | `main.js` -> `localStorage.setItem('igraspore_stats')`. |
| **Деградация крови (Gore fades to brown)** | 7/10 | Кровь красная при появлении, но должна темнеть/коричневеть со временем для реализма. | `world.js` / `render.js` -> `parts[i].life` меняет цвет. |
