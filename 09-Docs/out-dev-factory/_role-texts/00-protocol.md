```json
{
  "role": "05-DBA",
  "writes_product": false,
  "findings": [
    {
      "id": "D1",
      "severity": "BLOCKER|CRITICAL|MAJOR|MINOR|TRIVIAL",
      "where": "путь:строка",
      "what": "что сломано, бытовым языком",
      "why": "чем бьёт продукт/данные/юзера",
      "ac": "критерий приёмки одной строкой",

  ],
  "handoff_to": [{"role": "07", "note": "секрет в файле X"}]

```

Пустой `findings` = роль честно не нашла своего. Не выдумывать.

1. Прочитать все 9 JSON.

Сначала светофор-сводка: 🔴 BLOCKER / 🔴 CRITICAL / 🟡 MAJOR / 🟢 MINOR / ⚪ ICEBOX, каждое N целое (0 не прятать).
