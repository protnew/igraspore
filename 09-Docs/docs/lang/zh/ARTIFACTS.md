# iGraSpore — 项目文档资料

## 这是什么
水坑中100种真实微生物物种的浏览器模拟游戏。
Canvas 2D，单个HTML文件，无需服务器。受Spore（细胞阶段）启发。

## 仓库
- **GitHub**: https://github.com/protnew/igraspore
- **GitHub Pages**: https://protnew.github.io/igraspore/
