## 2. ДЕЛИТЬ (Q) и ЦИСТА/СПОРА (R) — воспроизведение

Таблица 2. Покадровая проверка (audit2-result.json)

| Действие | Что произошло | Тост | Причина |
|---|---|---|---|
| Q на 5-й секунде | ничего | «слишком молода» | `age < minAge` (biology.js:55) |
| Q на 10–80-й секунде | ничего | «перезарядка 19.7с … 34.0с» | игрок **сам** поделился без нажатия: `divP = o.isPlayer ? 0.5 : 0.02` (biology_update_interact.js:48-51) → `divCD` 20–34 с (mitosisCooldown) |
| Q после 40 с ожидания | +1 клетка, анимация 1,25 с | «Деление...» → «✌️ Разделился!» | работает, когда `canDivide` = true |
| R / кнопка ЦИСТА | 0 кадров в цисте из 16–20 | «Проснулся из цисты» | doCyst ставит `cyst=true`, а в том же кадре `if(o.isPlayer && o.cyst && o.energy>=18) o.cyst=false` (biology_update_interact.js:66-69). Энергия игрока почти всегда ≥18 |
| R при энергии 10 | 0 кадров в цисте | «Проснулся из цисты» | producer за 80 мс фотосинтезом набирает 10→40 энергии |
| ЕСТЬ / E | ничего | нет | `if(player.sp.cat==='producer') return false;` молча (main_events.js:153); вид по умолчанию — Synechocystis (producer) |

**Почему условия блокируют молча:** причина отказа деления выводится только (а) мелкой строкой `#hDivReady` внизу слева 12 px и (б) тостом на 1–2 с. Кнопка ДЕЛИТЬ не меняет вид (не серая, нет прогресса). Пороги массы в трёх местах разные: `canDivide` (biology.js:57-66: consumer 0.5×/1.5), `divideBlockReason` (biology.js:80-85: consumer 0.75×/3.0) и `updateDivReady` (ui.js, как в reason) — для охотников подсказка «масса 2.0/3.0» может врать. Ползунок `divRate<1` даёт случайный отказ с тостом «Пока нельзя делиться» (biology.js:93-94). Для ЦИСТЫ причины нет вообще — тост говорит обратное («Проснулся»). Для ЕСТЬ у растений — ни тоста, ни подсказки.
