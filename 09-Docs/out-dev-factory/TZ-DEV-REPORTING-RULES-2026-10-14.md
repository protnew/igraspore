## Правила

**R1. Отчёт-файл.** Каждый ответ (любой, включая промежуточный) записывается целиком в файл
`C:\Obsidian\New\Projects\08-iGraSpore_V2\09-Docs\out-dev-factory\REPORT-TZ-RELEASE-READY-2026-10-14-v2-<YYYYMMDD-HHMM>.md`
(время = момент ответа, UTC+3). Содержимое файла = текст ответа (один в один). Кодировка UTF-8. Файл коммитится вместе с этапом.

**R2. Путь перед финальной строкой.** Предпоследний блок ответа — полный путь к этому md в code block:
````
```
C:\Obsidian\New\Projects\08-iGraSpore_V2\09-Docs\out-dev-factory\REPORT-TZ-RELEASE-READY-2026-10-14-v2-20261014-2045.md
```
````

**R3. Git-строка.** Перед путём — строка: `HEAD <sha7> = origin (ahead 0 / behind 0); dirty: <N> записей (мои: <n>, чужой WIP: <m>)`. Если ahead > 0 — сначала push.

**R4. Commit + push после каждого этапа.** Этап не считается законченным без коммита и push; sha в отчёте.

**R5. Дата и время обязательны** в финальной строке: формат `ДД.ММ, ЧЧ:ММ (UTC+3)`.

**R6. Ровно одна финальная строка, последняя в ответе, одна из трёх:**
- `Закончен промежуточный ответ — ДД.ММ, ЧЧ:ММ (UTC+3). Дальше: <этап>, уже запущено: <команда/PID/лог>`
- `ПОЛНОСТЬЮ закончен ответ — ДД.ММ, ЧЧ:ММ (UTC+3)`
- `ОСТАНОВЛЕН — жду <что именно> от <кого> — ДД.ММ, ЧЧ:ММ (UTC+3)`, а над ней список «Осталось: …» по этапам.

**R7. Промежуточный = продолжаю.** «Промежуточный» допустим ТОЛЬКО если следующее действие уже запущено в момент отправки и исполнитель продолжает работать сразу после ответа. Отправил «промежуточный» и остановился — нарушение.

**R8. Запрет тихой остановки.** Если остались этапы, которые не требуют владельца (деньги, ключи, аккаунты, решение по вкусу, деплой), — остановка запрещена; переходи к следующему этапу. «Нет ответа владельца» блокером не является, если этап его не требует.

**R9. ОСТАНОВЛЕН — конкретно.** Блокер = конкретная вещь и конкретный человек/система («жду keystore .jks от Алексея», «жду квоту API от OpenRouter»). Плюс: что уже сделано, что осталось, что можно делать параллельно (и это делается).

**R10. ПОЛНОСТЬЮ** — только когда все этапы ТЗ закрыты по AC, дерево закоммичено (или остаток — перечисленный чужой WIP), HEAD = origin.

## Дерево решений (финальная строка)

```
Все этапы ТЗ закрыты по AC и запушены?
├─ да → «ПОЛНОСТЬЮ закончен ответ — …»
└─ нет → Есть этап, который можно делать без владельца?
     ├─ да → следующее действие уже запущено и я продолжаю?
     │    ├─ да → «Закончен промежуточный ответ — … Дальше: … уже запущено: …»
     │    └─ нет → НЕ отправлять; запустить следующий этап, затем ответить
     └─ нет → «ОСТАНОВЛЕН — жду <что> от <кого> — …» + «Осталось: …»
```

## Примеры

**Плохо (реальный ответ 14.10, 20:16):**

> Закончен промежуточный ответ — 14.10, 20:16

**Хорошо (продолжаю):**


## Самопроверка перед отправкой (чек-лист)

- [ ] md-файл REPORT-…-<YYYYMMDD-HHMM>.md создан и содержит этот ответ целиком
- [ ] полный путь к нему в code block прямо перед финальной строкой
- [ ] git-строка: HEAD=origin, dirty N (мои/чужие)
- [ ] этап закоммичен и запушен, sha указан
- [ ] финальная строка одна из трёх, с датой/временем (UTC+3)
- [ ] если «промежуточный» — следующее действие реально запущено (PID/лог), и я продолжаю
- [ ] если остановка — блокер требует владельца, список «Осталось» есть
- [ ] нет этапов без блокера, которые я бросаю

## AC

1. 100% ответов после 14.10 20:30 имеют свой REPORT-md, путь в code block перед финальной строкой.
2. 100% финальных строк — одна из трёх, с `ДД.ММ, ЧЧ:ММ (UTC+3)`.
3. После каждого «промежуточного» в течение 10 мин в репо есть новые изменения/коммиты.
4. Ни одного «ОСТАНОВЛЕН» без конкретного «что/от кого».
5. Каждый этап = коммит + push; HEAD = origin в каждом ответе.

## Самокритика правил (проверка на противоречия с правилами владельца)

- R1 «содержимое = ответ» vs R2 «путь в ответе»: путь в файле допустим (файл = копия ответа, включая путь) — не противоречит.
- R4 commit+push vs «не деплоить»: push в ветку ≠ деплой; деплой запрещён отдельно — совместимо.
- R8 vs правило владельца «не трогать чужой WIP»: продолжение этапов не даёт права коммитить/удалять чужой WIP; чужие файлы только перечисляются — совместимо.
- R6 «ровно одна строка» — формат промежуточной строки расширен хвостом «Дальше/уже запущено»; основа «Закончен промежуточный ответ — ДД.ММ, ЧЧ:ММ (UTC+3)» сохранена — совместимо.
- Противоречий не найдено.
